# ABN 官方名单入口与地图查询对比

验证日期：2026-11-17；邮编 NSW 2134；上限 20。两种来源不是同一组商家，地图按六类行业，官方数据按登记主体，不进行行业筛选。本轮测量第一步名单生成，不测 ASIC 续期成功率。

| 项目 | 实测 |
|---|---|
| 官方完整下载 | 193.55 秒，两个 ZIP 合计约 1 GB |
| 完整索引构建 | 352.58 秒 |
| 官方入口第一次计时（本机索引已就绪） | 0.001813 秒 |
| 官方入口后续 5 次中位数 | 0.001417 秒 |
| Bing 重新联网，仅目录名称，不读网站/ABR | 7.641 秒 |
| Bing 后续网站读取与登记核验 | 26.109 秒 |
| Bing 两阶段合计 | 33.750 秒 |

官方入口计时包含 collect 返回名单，不包含浏览器渲染和 CSV 写入。下载与索引是首次/更新成本，不应混入日常毫秒级查询，也不能省略成本。Bing 目录请求均 cached=false；补充核验调用现有 refresh=True 路径，个别内部缓存行为以现有模块为准。单次网络测量不代表恒定速度。

官方 20 个主体展开 23 行，20 个 ABN，10 条 Business Name、18 行可归类 ACN；13 行只有法定名称，保留但不查商号续期。Bing 20 家原始目录中 ABN 和 Business Name 均为空；补充核验后各有 3 条、ACN 2 条。ABN/商号字段非空不等同于本轮已确认 Renewal Date。

快照：2026-11-11T12:20:05，全国 Active ABN 8,938,907。NSW 2134 有 10,091 个 Active 主体，展开 10,521 行，其中 1,662 条 Business Name。它是主要经营地点邮编口径，不是全部实体门店或全部公司；主体包括个人、信托等。

## 实现与验证

- 官方 ZIP 完整下载并解析 20 个 XML；保留快照来源和时间；索引原子替换，下载/解析失败保留旧索引。
- ACT 筛选、BN/TRD 区分；同一 ABN 的不同 Business Name 单独保留，导出不会合并丢失。
- ACN 明确类型直接提取；未定类型仅在澳大利亚私人/公众公司、九位编号校验成功且与 ABN 后九位一致时归类，并保存原始 ASIC 编号和分类依据。
- 真实官方 23 行进行了隔离队列构建：10 项待 ASIC，13 项缺商号跳过；没有访问 ABR 名称搜索，没有调用 OCR，没有编造日期。
- 连续任务分页、每批 20 行、CSV 保存和下一邮编推进通过隔离测试；此次未以新官方名单驱动安装插件重跑所有续期，也没有宣称验证码消失。
- 110 项 Python 测试、28 项插件 JavaScript 测试通过；页面脚本语法检查通过。
- 浏览器真实提交官方来源 NSW 2134 / 20，显示 23 行，ABN/ACN 可见；HTTP 下载 CSV 为 23 行，无页面控制台错误。

## 使用

名单来源选择 ABN 官方公开数据。单次点击开始自动整理；连续查询需先用当前配对码连接插件并等待连续队列，再勾选网页的每批等待 ASIC 核对选项，设置起止邮编后启动。服务重启后需要重新配对。没有勾选 ASIC 时只保存名单，不查日期。

地图来源保留。要找指定行业的实际门店用地图；要批量获取登记名称及 ABN 并查商号续期用官方入口。官方入口不能提供 Renewal Date；真正的 ASIC 验证仍需人工完成。

数据来源：[ABN 官方 Bulk Extract](https://abr.business.gov.au/Tools/BulkExtract)。
