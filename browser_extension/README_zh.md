# Registrypro ASIC Assistant · v2.4

已经安装的用户在扩展弹窗点“加载本机更新”，然后重新从工作台复制配对码。首次安装按下方原说明操作。

当前按 ABN 与 Business Name 组合安排查询，公司年度审核日为独立可选项。支持强制刷新、24 小时缓存、当前记录／预期 ABN 筛选、最多 10 页、动态点击有限重试、主系统暂停同步和本机队列恢复。

“等待系统连续邮编队列”用于配合工作台的“每批等待 ASIC”选项；普通 20 家名单重跑不要勾选等待模式，选择“最近一次查询”并勾选强制刷新。

“启用本次截图 OCR 备用”请求当前标签页临时截图能力，只在 ASIC 工作页使用；未授权时仍使用 DOM 文字。截图只发送给本机服务，RapidOCR 的安装和限制见根目录使用说明。仅截取可见区域；缺少必要标签或编号时不会采纳。

服务重启／插件重载后，重新粘贴配对码再点继续可恢复保存队列。自动队列只查询公开免费资料，不购买报告、不发送邮件、不处理验证码。

v2 已完成有人工恢复的 20 家实跑；v2.1 的独立验证记录见 VALIDATION-2026-11-17.md，不把旧结果当作自动恢复验收。

## 连续抓取续期日期

正常运行不依赖 Codex 或 Computer Use。完成配对后，在插件勾选“等待系统连续邮编队列”并连接；在工作台勾选“每批等待 ASIC 插件核对后保存并推进邮编”，设置邮编范围后启动连续任务。保持本机服务与 Chrome 运行。每批按工作台所选来源取得名单：ABN 官方入口按州和邮编筛选 Active 主体并展开商号；地图入口先研究 ABN。插件读取 ASIC 摘要，保存 CSV 后推进邮编。

已知 ABN 时，在 Business names index 的 Number 栏查询；ACN 用于可选的公司查询。Renewal date 与公司的 Next review date 分开保存。v2.4 确认的是具体 Business Name 与续期日期，不以地址一致为必要条件，不冒充已核实门店经营主体。

v2.1 在文档开始阶段加载读取脚本；空白持续 12 秒或非摘要内容 45 秒没有推进时，第一次刷新，第二次回到官方搜索入口。每项最多两次恢复，后台总期限 180 秒，恢复不重置总期限；失败保存原因后继续下一项。检测到验证页面时停止页面操作，持续存在则暂停队列，交由用户处理。

v2.2 将验证等待与手动暂停分开：验证期间只观察页面，不点击、刷新或解决验证码。验证提示消失且正常 ASIC 页面稳定 5 秒后，自动恢复该队列；连续邮编任务同步等待，不提前导出或推进。手动暂停／停止不会被自动恢复覆盖。隐藏、透明或屏幕外的验证 iframe 不作为可见验证信号。等待验证的时段不计入当前项 180 秒执行期限，但不会重置已用时间。

# Registrypro ASIC Assistant

这是本机 Registrypro 的 Chrome / Edge Manifest V3 扩展，不是商店已审核扩展。

## 安装与首次连接

1. 打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”。
2. 选择本项目 `browser_extension` 文件夹（不要选择 ZIP 文件）。
3. 启动项目的 `start.cmd`，打开 `http://127.0.0.1:8765/`。
4. 展开“ASIC 浏览器插件”，点击“复制配对码”。打开插件弹窗粘贴配对码。
5. 选择名单与 5/15/30/60 秒间隔，点击“连接并开始”。插件创建一个专用 ASIC 标签页并依次查询。查询时会激活该标签页，避免后台计时延后；建议使用独立窗口，不要在工作页同时手动搜索。可以关闭弹窗，保持 Chrome 与本机服务运行。
6. 页面会显示队列进度，结果写回名单；重新下载 CSV 获取最新名称、日期与来源。

本机服务重启后配对码失效，需重新复制。插件暂停／继续保持当前队列；完全关闭 Chrome 或停止本机服务后重新连接并启动任务，已保存结果仍保留。系统中的“停止浏览器队列”用于结束旧队列，再新建名单任务。

## 读取与匹配规则

- 从本机名单建立任务，优先采用已发现的官方名称和编号，也对目录名称进行 ASIC Business Names 搜索。
- 在真实浏览器渲染的免费摘要中读取 Business Name、ABN、持有人、Principal place of business、Renewal date；公司摘要读取 ACN 和 Next review date。
- 名称必须与指定任务准确对应；服务端再次检查官方域名、ABN、ACN、登记状态，以及 ABN Lookup 当前名称。
- 商号日期要求名称对应、当前 Registered、明确的 Renewal date；地址不同或不完整仅记录到说明。ABN/ACN 有则补充，缺少编号仍可确认商号日期；保留既有人工核验／冲突资料，不因新规则擅自覆盖。
- 商号日期与主体身份分开标记；只有名称合理对应且包含有效续期日的摘要才进入确认字段，名称仍有歧义的日期保留在候选列。
- ASIC 可能保留上一个查询页面。插件核对摘要名称，必要时改用页面内搜索；不会把上一个企业的日期写入下一家。
- 同名多条或名称匹配不足仍为候选；取消登记、缺少日期不能确认。技术故障页等待 15 秒后有限恢复，最多两次，失败标注 ASIC 技术故障／待重试，不作为查无结果。验证码由用户处理，插件不绕过。
- 不选择付费报告、不加入购物车、不登录、不修改 ASIC 登记资料、不发送邮件。

## 权限与数据

仅申请 `storage`、`alarms`，以及 `connectonline.asic.gov.au`、`127.0.0.1` 的主机权限。运行代码只访问本机端口 8765 与 ASIC RegistrySearch 公共页面，不读取其他网站、浏览历史、密码或 Cookie。

配对码存储在 Chrome 会话存储中。摘要文本及判定依据保存至本机 `output/asic_browser_evidence/`，采纳的核验结果存于 `output/registration_browser.json`；它们不提交 GitHub。已人工核实／标注冲突的数据受保护。
